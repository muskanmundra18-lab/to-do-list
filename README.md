# To-Do List

A simple browser-based task-list application built using **HTML, CSS, and JavaScript**.

## Overview

The project focuses on building an interactive front-end application for organizing tasks and experimenting with DOM manipulation and JavaScript event handling.

## Features

- Task-list interface
- Multiple list pages/views
- Interactive task controls
- Custom styling
- JavaScript-based interaction

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

```text
to-do-list/

├── list4.html
├── list5.html
├── list6.html

```

## Run Locally

```bash
git clone https://github.com/muskanmundra18-lab/to-do-list.git
cd to-do-list
```

Open `index.html` in a browser.
